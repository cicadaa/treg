# The GTM world

Who stands on each landscape of /gtm-leaderboard. Row order is rank: the first row of a landscape
stands on its summit. `id` is the person's lasting name for votes (lower-case letters, digits and
hyphens; never reuse or rename one, or their upvotes are lost). `landscape` is one of volcano,
iceberg, forest, creek, flower. `photo` is a file in this folder; empty uses the X profile
picture, then initials. `followers` is the X follower count. `intro` is a few words on what they
do, shown under the name. `company` is where they work, and `site` its bare domain, whose icon
shows beside it; leave either empty when unknown. `bio` is the X bio as written, shown on
the card a photo opens.

These rows are made-up sample people so the page has something to show: none of them is a real
person, and none has an X handle, so no row links to a real account.
